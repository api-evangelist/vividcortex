# VividCortex (SolarWinds Database Performance Monitor)

> VividCortex is a SaaS database performance monitoring platform, now part of SolarWinds and sold as SolarWinds Database Performance Monitor (DPM). Lightweight per-host agents capture and analyze every query against MySQL, PostgreSQL, MongoDB, Redis, Amazon Aurora, and SQL Server with always-on, sub-second visibility. A public REST API (v2) exposes hosts, metrics and time-series data, observed queries and samples, timeline events, and alert configuration.

## API
- [VividCortex DPM API v2 reference](https://docs.vividcortex.com/api/): REST API, base URL https://app.vividcortex.com/api/v2, Bearer API token auth.
- [API tokens & authentication](https://docs.vividcortex.com/api/basics/api-tokens/): create a per-environment token in DPM Settings → API Tokens; pass as `Authorization: Bearer <API_TOKEN>`.
